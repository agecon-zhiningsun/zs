# First-Time Publish — `zs.github.io`

Your GitHub username is `agecon-zhiningsun` and your repository stays named `zs.github.io`.

## Upload

1. Open `https://github.com/agecon-zhiningsun/zs.github.io`.
2. Upload **the contents of this package** to the repository root.
3. Confirm that `index.html` is visible directly in the repository root.
4. Commit the upload to the `main` branch.

## Turn on GitHub Pages

1. In the repository, open **Settings**.
2. Click **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main**.
5. Select folder **/ (root)**.
6. Click **Save**.
7. Wait for the Pages deployment to finish.
8. Open `https://agecon-zhiningsun.github.io/zs.github.io/`.

## Update later in RStudio

Clone once:

```bash
git clone https://github.com/agecon-zhiningsun/zs.github.io.git
```

Open `zs.github.io.Rproj` in RStudio. Then edit → save → Git tab → stage → commit → push. GitHub Pages will update automatically.
